## 一、判定框架：三级判据 + 组合规则

### 1.1 三级判据（O-9b 原文口径）

| 级 | 方式 | 谁判 | 硬性 | 本文定位 |
|---|---|---|---|---|
| **①** | **状态/数值断言** | 机器 | 最硬，可独立通过 | 页面级状态 + HTML 模块 DOM（见 §三） |
| **②** | **截图像素 diff** | 机器 | 定量（diffRatio + bbox + hotGrid） | 全部 51 点必截，canvas 内画面**主判据** |
| **③** | **AI 视觉审阅** | AI | **不得单独作通过依据** | 仅灰区；双条件通过（见 §5.2） |

### 1.2 组合规则（判定流程图解）

```
每点执行顺序：
  ① 断言（页面级）──不过──▶ 直接判「不通过」（不等价），差异归因 → 挂账/修复
        │过
        ▼
  ② settle（连续两帧变化率 ≤ 4%）──超时──▶ 标注「未稳定」（A 类正常）→ 走关键帧策略
        │稳定
        ▼
  ③ 截图 → diffPng(A, B)（threshold=12, gridSize=40）
        │
   diffRatio ≤ 等价线 ──▶ 判「等价」（记证据：diffRatio + bbox + hotGrid）
        │超
   diffRatio ≤ 灰区线 ──▶ ③ AI 审阅 ──双条件──▶ 「等价（AI 辅助）」/「不等价」
        │超
   diffRatio > 灰区线 ──▶ 判「不等价」→ 逐条裁定：修复 or 挂账（L2 台账）
```

### 1.3 「A/B 差异优先」原则（派单验收 ③）

**判定标准全部以「B 与 A 的差异特征」表述**，不写「按钮应该是蓝色」「字号应为 54」这类凭空期望。理由：

- B 版的正确性定义 = **与 A 版（modder 原产物）行为/视觉等价**，不是与设计稿等价
- 期望外观无法机器判，只能 AI 判 —— 会把 ③ 升级成主判据，违反 O-9b
- 例外：仅当 A 版本身可被证明有缺陷时（如 A 版某处明显渲染错误且迁移文档已记录），才以「设计规范 + 迁移记录」表述期望，且必须双产物对比留证

> 实例对比：
> - ❌ 凭空描述：「天赋卡片标题字号 60，行高 1.35」→ AI 审，不可机器判
> - ✅ A/B 差异：「B 与 A 的 diffRatio ≤0.5%，且 hotGrid 不落在标题文本区（y<120 区域）」→ 机器可判

## 二、画面五分类与 diff 阈值体系

### 2.1 分类依据（按渲染特征，不按系统）

| 类 | 定义 | 时序抖动 | 主要噪声源 | 代表点 |
|---|---|---|---|---|
| **S** | 静态界面（无动画、布局固定、可 settle） | 无 | 抗锯齿 + 字体 hinting | 天赋图鉴、商店、背包、设置、语言选择、挑战选择 |
| **P** | 弹窗/提示（有出现过渡，settle 后为静态） | 出现瞬间 | 过渡帧 + hover 态 | 欢迎弹窗、获取提示、结算界面 |
| **H** | 战斗内 HUD / 计量条（常驻小部件，可能数字刷新） | 低 | 数字 hinting + 微位移 | 天赋 HUD、念力层数、P5X 顺序条、呼符计量条、PT HUD |
| **B** | 战斗全景（整屏 + 多元素 + 播报） | 高 | 时序抖动 + sprite 位移 | 深渊战斗、年代天赋触发、爆发结算 |
| **A** | 动画演出（光环/粒子/技能特效，**不可 settle**） | 极高 | 逐帧内容不同 | 传说弹窗光环、解明招式、效果触发 |

### 2.2 阈值表（diffRatio = 差异像素 ÷ 总像素；png.mjs：threshold=12 单通道，gridSize=40）

| 类 | 等价线 | 灰区线 | 灰区判定 | 超灰区 |
|---|---:|---:|---|---|
| **S** | ≤ **0.5%** | 0.5% ~ 5% | AI 审阅 | 不等价 |
| **P** | ≤ **1%** | 1% ~ 8% | AI 审阅 | 不等价 |
| **H** | ≤ **2%** | 2% ~ 10% | AI 审阅 | 不等价 |
| **B** | ≤ **3%** | 3% ~ 15% | AI 审阅 | 不等价 |
| **A** | ≤ **5%** | 5% ~ 20% | 关键帧 + AI | 不等价 |

**阈值依据**：
- S 类最严：静态界面两版资源一致时差异应趋近 0；0.5% 以上通常就是**真差异**（文本内容、字号 token 漂移、间距标度偏差）——正是 S7 迁移要抓的东西
- A 类最宽：动画逐帧内容本就不同，settle 失败属预期；用关键帧策略后仍需容忍插值差异
- 全部为**初值**：F-15 的任务是用「已知等价画面」实测误报率（目标 <5%）后调优；本文阈值即 F-15 的调优基线

### 2.3 差异特征约束（一硬两软）

| # | 约束 | 性质 | 口径 |
|---|---|---|---|
| **C-1** | **尺寸一致** | 🔴 **硬否决** | `sameSize=false` ⇒ 直接不等价（画布/缩放配置差异，无 diff 意义） |
| **C-2** | 分散度 | 🟡 软信号 | `hotGrid` 热区计数（40px 网格）：集中在少数点 = 可解释噪声（hinting）；**触顶 40** = 疑系统性渲染差（缩放/字号/资源）—— 作灰区 AI 审阅输入 |
| **C-3** | 可归因性 | 🟡 软信号 | 每个热区能对应到 U-7 组件元素或已知噪声源；无法归因 ⇒ 升级 AI |

> ⚠️ **为什么不把「bbox 面积」当硬约束**：bbox 是全部差异像素的**包围盒**，正常等价画面（顶部菜单 + 底部按钮各有 hinting 噪声）也会横跨全屏 —— bbox 面积大 ≠ 差异分散。分散度以 hotGrid 计数为准（`spreadScore()`，见 §六）。

## 三、断言设计规范（🔴 对 F-12 的修正）

### 3.1 Phaser canvas 陷阱

F-12 catalog 中以下断言**对 Phaser 渲染文本无效**（canvas 内文本不进 DOM）：

```js
// ❌ 恒失效（除非页面恰好有其他 DOM 文本含该词）
expr("document.body.innerText.includes('天赋')", "界面含『天赋』字样")   // talent.codex
```

**修正规则**：

| 渲染通道 | 可断言内容 | 判据级 |
|---|---|---|
| **Phaser canvas** | 仅页面级：canvas 挂载、帧活跃（方差）、无新增异常、资源零失败 | ① |
| **HTML DOM**（legendary-popup、欢迎弹窗等） | innerText / 元素存在性 / 计算样式 | ① |
| **canvas 内视觉**（文本内容、数字、图标、布局） | **只能 diff**（②），期望差异由 A 版定义 | ② |

**建议 F-14 落场景时**把 canvas 类点的 expr 断言改为：

```js
// ✅ 页面级（canvas 场景通用三件套）
expr("!!document.querySelector('canvas')", "canvas 已挂载"),
noNewErrors(),
// 资源完整（session.diagnostics 汇总，runner 侧汇总）
```

若后续改版产物（B 版）暴露全局诊断钩子（如 `window.__pkrc` 场景状态），可加**状态/数值断言**（如念力层数、倍率数值）—— 这是唯一能让「数值正确」脱离 diff 的路径，**建议列入 B 版产物需求**（移交全栈，见 §七）。

### 3.2 HTML 模块专项（legendary-popup）

`legendary.popup` / `legendary.helper` 是 **HTML 渲染**（不走 Phaser 文本管线，U-7 C-8）：
- DOM 断言**可用**：弹窗出现（innerText 含传说名）、关闭后移除
- diff 仍执行：HTML 渲染同样受字体 hinting 影响，且光环动效使时序抖动大 → A 类阈值
- ⚠️ 其 Token/i18n 适配层不适用（U-8 波次 7 单独定稿）—— 走查发现差异**不挂 S7 账**，挂 legendary-popup 专项

## 五、升级与裁定规则

### 5.1 灰区判定矩阵

| diffRatio 落位 | bbox/hotGrid 可解释 | 裁定 |
|---|---|---|
| ≤ 等价线 | 任意 | **等价**（记证据） |
| 灰区内 | 可解释（文本边缘/hinting） | AI 审阅 → 双条件 → 等价（AI 辅助） |
| 灰区内 | 不可解释 | **升级**：扩测（重跑该点 3 次取稳定性）+ AI 逐热区审 |
| > 灰区线 | 任意 | **不等价** → 逐条裁定（修复 or 挂账） |

### 5.2 AI 审阅双条件（O-9b 铁律落地）

灰区点判「等价」必须**同时**满足：

1. **AI 明确判等价**并给出依据（描述差异特征符合噪声模式：抗锯齿边缘/hinting/插值）
2. **定量特征佐证**：diffRatio 在灰区内、bbox 有界（C-1）、hotGrid 可解释（C-2）

仅 AI 说「看着没问题」→ **不记通过**，维持灰区，进证据包待所有者复核。

### 5.3 关键帧策略（A 类 4 点 + B 类兜底）

动画演出 settle 必失败，改：

1. **首帧**：动画触发后第 1 个稳定帧（元素出现但未大幅运动）
2. **尾帧**：播报/结算文本稳定后（文本可 diff）
3. **过程帧不判等价**（逐帧内容本就不同）——只用于 AI 审阅「演出是否存在/顺序正确」

### 5.4 差异归因路径（不等价时）

```
diff 超灰区
  ├─ sameSize=false ────────▶ 画布/缩放配置差（320×180 / scaleFactor）→ 全栈
  ├─ 文本区热区集中 ────────▶ 字号 token / 行高 / i18n 缺 key → UI（U-9/U-10 账）
  ├─ 全屏分散 ─────────────▶ 资源缺失/渲染管线差 → 全栈（A4 补迁 or 资源）
  ├─ HUD/计量条局部 ────────▶ 对应 C 层组件（U-7 归因表）→ UI
  └─ 配色差异（同布局不同色）▶ 内联 hex 未登记（95 种）→ UI palette.extra
```
