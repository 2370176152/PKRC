## 一、重构总体策略（三铁律）

| # | 铁律 | 来源 |
|---|---|---|
| **R-1** | **不新建平行入口**——所有文本经上游 `addTextObject` + `{level}/{lineHeight}`；改版自建入口收敛而非保留 | U-3 C-1 |
| **R-2** | **能复用不新造**——窗口 `addWindow`、选项渲染、滚动条、计量条全部对标上游；确需自建的先登记例外 | U-7 审计 |
| **R-3** | **文案先于动效**——每个系统动界面之前，其 i18n 批次（B1–B6a）必须先就位；改词不改代码 | U-2 分批 |

**每个系统的统一改造五件套**（承 U-3 §4.2 冻结范式）：

```
① 字号  裸值 → { level }            （U-6 §三）
② 行高  手调 → { lineHeight }        （U-6 §四，白名单除外）
③ 间距  裸数 → Spacing.*            （U-6 §五）
④ 配色  hex → TextStyle / palette.extra 登记
⑤ 文案  内联 → M.t("pkrc.<ns>:<key>")  （B0–B6）
```
