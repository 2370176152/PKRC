## 零、清单设计原则

1. **9 组合全覆盖**：3 分辨率 × 3 缩放比（派单硬要求）
2. **每项 4 个检查点**：裁切 / 模糊 / 溢出 / 遮挡（派单硬要求）
3. **按界面风险分级**：不是 9×N 全量，而是**风险界面优先**（避免 S7-6 变成体力活）
4. **可勾选**：每格一个 checkbox，走查完即验收

## 三、检查点定义（4 项，每格必查）

| 检查点 | 判据 | 常见症状 |
|---|---|---|
| **① 裁切** | 文本/组件完整可见，不被窗口、屏幕边缘、遮罩切断 | 长文案被 `wordWrap` 宽度截断；`maxLines` 后文字消失 |
| **② 模糊** | 文字边缘锐利，无重影、无半像素偏移 | `setScale(1/6)` 非整数倍缩放导致字形发虚；DPR 不匹配 |
| **③ 溢出** | 文本不超出其容器 / 窗口 / 面板边界 | `micro=36` 把 26–32px 拉大 38%，紧凑表格撑破 |
| **④ 遮挡** | 文本不被其他 UI 元素、光标、滚动条压住 | 深度排序问题；新 token 字号变化后覆盖关系改变 |

> **额外检查点（P0 界面加查）**：
> - **⑤ 光标/滚动条对齐**：字号变化后，键盘光标框是否仍与文本行对齐
> - **⑥ 触屏热区**：44px 最小触摸目标（`pointer: coarse` 下）

## 五、高危专项检查（S7-6 必做）

| ID | 专项 | 位置 | 检查方法 |
|---|---|---|---|
| **H-1** | 26px → 36px（**放大 38%**） | L1033 守门员天赋文本 | 守门员 HUD 是否溢出；超长天赋名是否被截 |
| **H-2** | 76px → 66px（缩小 13%） | L371 糖果/好感计数 | 数字位数变化时是否错位 |

| **H-4** | 白名单 `fontSize:0` | L472 三被动 | 「三被动」文字**必须保持隐形** |
| **H-5** | 动态字号 30↔40 | L1033 守门员 HUD | 天赋 4 条 / 5 条边界各查一次 |
| **H-6** | 动态字号 `messageFontSize()` | L456 消息框 | 长消息（>5 行）是否正常收缩 |
