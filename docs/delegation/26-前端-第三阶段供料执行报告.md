## 二、F-7 —— 上游 pointer 缺口承接方案

**文档**：`docs/delegation/23-F7-上游pointer缺口承接方案.md`

### 2.1 三条硬结论

| # | 结论 |
|---|---|
| 1 | 38 处 canvas 交互点**全部**给出「上游文件 + 接入函数」（§二 全表）；改版外挂 ~34 处，上游可复用仅 6 文件（模态族） |
| 2 | 承接方式 = **唯一入口 + 声明式注册表 + 12 场景适配器 + legacy-bridge**；**不在 handler 里加 pointerdown** |
| 3 | **`bindKey` 只覆盖虚拟手柄（DOM 层）**；canvas 业务界面 bindKey 覆盖不到 → 必须走统一拦截层 |

### 2.2 统一拦截层（不散落改上游）

```
pointer-manager（唯一 canvas 入口，替代 38 处散落注册）
  → gesture-resolver（F-6）→ input-arbiter（F-6）
  → interaction-registry（声明式 InteractionSpec[]）
  → scene-adapters（F-8 的 13 个）
  → legacy-bridge → ui.processInput(Button) / handler.setCursor(n)
```

**三条铁律**：① handler 内不新增 pointerdown；② 只用公开 API（`processInput`/`setCursor`/`setMode`），不碰私有 `onXxxPointer`；③ 灰度期旧实现保留，`priority` + 同帧去重防双触发。

## 四、F-9 —— `inputMethod` 接入点确认

**文档**：`docs/delegation/25-F9-上游inputMethod接入点确认.md`

### 4.1 读写点

| 类别 | 数量 | 位置 |
|---|---:|---|
| **声明** | 1 | `battle-scene.ts:344 public inputMethod: string` |
| **写点** | 1 方法 | `ui-inputs.ts:36 detectInputMethod`（仅由 `input_down` 调用） |
| **读点** | 7 直接 + 2 间接 | `ui.ts:431/653/657`、`starter-select:3015/3020`、`pokedex-page:2244/2250`（+ `run-info:186/248` 经 `getGamepadType()`） |

### 4.2 关键发现（🆕）

**7 个读点里有 3 处把 `inputMethod` 当作「精灵图集 key」**（`run-info` ×2 / `starter-select` / `pokedex-page`）：
```ts
new Phaser.GameObjects.Sprite(globalScene, 0, 2, gamepadType, …)   // gamepadType 当 texture key
```
⇒ 若令 `inputMethod = "mouse"`，会去找名为 `mouse` 的图集 → **缺资源**。

### 4.3 结论：**采纳「做法甲」= 零侵入扩展**

| 项 | 结论 |
|---|---|
| 上游是否已有 `"mouse"`？ | ❌ 无（实测 `grep '"mouse"' src → 0`）；值域仅 keyboard/touch/gamepad |
| 是否走「扩展」？ | ✅ **是** —— `inputMethod` 类型是 `string`，新增值无需改类型；且**做法甲连取值域都不改** |
| 做法甲 | 鼠标事件以 `controller_type:"keyboard", isTouch:false` 注入（虚拟手柄同款先例）→ 上游 **0 行改动**；7 读点语义不变 |
| 键鼠区分 | 由 `src/input/input-arbiter.ts` 的 `lastDevice`（F-6）内部承担 |
| 做法乙（备选） | 真要 `inputMethod="mouse"`：加 1 个 `else if` 分支 = **扩展**；但须同步 3 处 atlas 站点做 `mouse→keyboard` 映射 |

**复用机理**：鼠标产出的 `Button` 经 `globalScene.inputController.events` 注入 `input_down` → `UiInputs.listenInputs`（不改）→ `getActionsKeyDown()[button]()`（不改）→ `ui.processInput(Button)` ⇒ **一键复用上游全部动作表语义**（方向+振动 / 白名单 / 模式 switch / `disableMenu` / `pendingPrompt`）。
