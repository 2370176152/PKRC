## 一、Ground Truth：为什么必须重新数

### 1.1 三种数法的对比

| 方法 | 结果 | 问题 |
|---|---|---|
| 朴素 grep `"[^"]*[一-龥][^"]*"` | **2,440** | ❌ 337 个模板字面量内含 `"`，正则错位配对，**既漏也重** |
| 转义感知正则 | 2,404 | ❌ 仍不识别模板字面量边界 |
| **字符级扫描器（区分 `"` / `` ` ``）** | **2,839** | ✅ **Ground truth** |

### 1.2 严格解析结果

| 类别 | 条数 | 去重 | 说明 |
|---|---|---|---|
| **静态字符串**（`"..."` 含中文） | **1,861** | 1,573 | i18n 抽取的**主体**，一一对应 |
| **动态模板**（`` `...` `` 含中文） | **978** | 959 | 其中 **913 条含 `${}` 插值** |
| **合计** | **2,839** | — | — |

> **证据**：`grep -c '`' 产物` → 5,436 个反引号 ≈ 2,718 个模板字面量，其中 **337 个内含双引号**。
> 这些内部的 `"` 让朴素正则把两个不相邻的片段拼成一个假匹配 —— 这就是 2,440 不可信的原因。

### 1.3 静态 vs 动态的抽取难度差异

| 类型 | 改造前 | 改造后 | 难度 |
|---|---|---|---|
| 静态 | `"返回"` | `t("pkrc.common.return")` | 🟢 机械 |
| 动态（无插值） | `` `确定要撤离吗？` `` | `t("pkrc.soudache.retreatConfirm")` | 🟢 机械 |
| 动态（有插值） | `` `需要 ${U}PT，当前只有 ${_}PT` `` | `t("pkrc.soudache.ptInsufficient", {need: U, have: _})` | 🟠 **需人工定变量名** |

> ⚠️ **913 条插值模板是工作量的真正主体**。派单的「2,440 条」如果按静态串估工，会**严重低估**。

## 七、附录：扫描器（可复现）

```python
# u2_scan.py —— 字符级扫描，区分 " 与 `，正确处理转义
import re, json
CJK = re.compile(r'[\u4e00-\u9fa5]')
src = open("game/server/dist/assets/loading-scene-By2k7Qfx.js", encoding="utf-8", errors="replace").read()

def scan(s):
    out, i, n = [], 0, len(s)
    while i < n:
        c = s[i]
        if c in ('"', '`'):
            q, j, buf = c, i + 1, []
            while j < n:
                ch = s[j]
                if ch == '\\' and j + 1 < n: buf.append(s[j:j+2]); j += 2; continue
                if ch == q: break
                buf.append(ch); j += 1
            out.append(('dquote' if q == '"' else 'tquote', i, j, "".join(buf)))
            i = j + 1
        else:
            i += 1
    return out

toks = scan(src)
dq = [t for t in toks if t[0] == 'dquote' and CJK.search(t[3])]
tq = [t for t in toks if t[0] == 'tquote' and CJK.search(t[3])]
print(f"静态: {len(dq)}  动态模板: {len(tq)}  合计: {len(dq)+len(tq)}")
```

> ⚠️ **不要用 `grep -o -E '"[^"]*[一-龥][^"]*"'`** —— 337 个模板字面量内含双引号，会错位配对。
