## 一、最重要的结论：A0 不存在真实阻塞

任务下达时的前提是「A0 卡住，后端只能做旁支」。**实测推翻了这个前提**——原 3 个阻塞项里，2 项是判断偏差，1 项根因归错。

| # | 原判断 | 实测结论 |
|---|---|---|
| **BLOCK-1** | 便携 Node v16 vs 上游要求 v22 → 「构建必然失败」 | ⚠️ **非阻塞**。便携 v16 只跑**运行期**服务（35 项测试全绿），构建期用系统 **v22.22.2**。两者职责不同，本就无需统一。附带发现：上游 beta 现状实为 **v24.9.0 + pnpm@10.34.5**，「Node 22」的说法对 2025-04 成立、对 beta 已过时 |
| **BLOCK-2** | pnpm 未安装 | ✅ **可解**：系统 Node 22 自带 **corepack 0.34.6** → `corepack prepare pnpm@10.34.5 --activate`。无需 `npm -g` |
| **BLOCK-3** | clone 卡住，根因是 ghproxy 代理 | ❌ **根因归错了**。**直连 GitHub 可用**；真凶是 `--filter=blob:none` 的 promisor **二次拉取**。实测 `--depth 1 --single-branch --branch beta` → **21 MB / 数十秒**，`src/` 完整 |

**顺带把 A0-2 也做了**：用 locales 中文目录改名做硬特征，把上游版本**上界锁死在 2025-09-22**（locales commit `1d4c0199` 删除 `zh-CN`），比原文档的「2025-06~08」更紧。

> **新识别的真实瓶颈**：不是 clone，而是 **C-4「魔改点 → 上游文件」映射表无人承接**。建议项目所有者指派。

## 三、验收：35 项测试全绿

```bash
cd game/server
NODE_PATH=../../shared/runtime/node_modules ../../shared/runtime/node.exe test-server.cjs
# → 总计 35 项：通过 35，失败 0，跳过 2
```

覆盖派单 §2.6 的 **1-A ~ 1-H 全部 8 项** + §3.2 的 **7-A / 7-B**，另加参数解析、端口优先级、日志格式、依赖白名单扫描等。

**端到端实测**（真实 825 MB dist，非 mock）：`index.html` 200、`assets/index-D3KKGO7Y.js` 200（2.6 MB）、`locales/zh-CN/common.json` 200、端口占用 → 退出码 1 + ERROR 落盘 + 修复建议、轮转 12 → 10 份。

### 测试真实抓到的 3 个缺陷

| # | 缺陷 | 为什么危险 |
|---|---|---|
| 1 | `flatten` 用在 `stringify` **之前** | 多行 stack 漏网 → 一条日志占多行，`grep '^\['` 失效 |
| 2 | `String.replace` 用了**字符串式** repl | 日志正文含 `$&`/`$1` 时被**二次展开**，内容被静默篡改 |
| 3 | `args.logDir \|\| DEFAULT` | `--log-dir=`（用户显式要求禁用）被静默折回默认目录 |

> 这三条**光读代码发现不了**——正是这套测试的存在理由。

## 六、给全栈的一句话

```bash
# 上游 clone（直连即可，去掉 ghproxy）
git clone --depth 1 --single-branch --branch beta \
  https://github.com/pagefaultgames/pokerogue.git upstream-pokerogue
git -C upstream-pokerogue submodule update --init --depth 1 assets locales

# pnpm（不污染全局）
corepack prepare pnpm@10.34.5 --activate

# 构建用系统 Node 22（不要用 shared/runtime/node.exe，那是 v16 运行期用的）
node --version   # → v22.22.2
```

`--depth 1` 会丢历史，所以**版本定位不要靠主仓库历史**，走 `pokerogue-locales` 独立仓库（已完成，上界 2025-09-22）。
