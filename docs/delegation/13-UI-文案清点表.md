## 三、i18n 命名空间规范（S7-4 落地标准）

### 3.1 键命名规范

```
pkrc<系统>.<模块>.<键>
```

**已落地先例**（天赋系统，S7-4 应沿用此结构）：

```json
// 现有 game/server/dist/locales/zh-CN/talent.json（部分）
{
  "shop": {
    "title": "天赋商店",
    "selectTalent": "选择一个天赋",
    "refreshCost": "刷新 ({{cost}}PT)",
    "insufficientPT": "本局PT不足"
  },
  "rarity": { "common": "普通", "rare": "稀有", "epic": "史诗", "ultimate": "终极" },
  "talents": {
    "yiban_gongji": {
      "name": "一般之力·攻击",
      "shortDescription": "一般属性宝可梦物攻/特攻/速度+10%",
      "fullDescription": "提升队伍中一般属性宝可梦的攻击能力。\n物理攻击+10%，特殊攻击+10%，速度+10%。\n可叠加，最多5层。"
    }
  }
}
```

> 🔍 **重要发现**：现存的 `talent.json` **顶层键没有 `pkrc` 前缀**（是 `shop.*` / `rarity.*` / `talents.*`）。
> **与 v1 派单 04 §3.2 的 `pkrc.talent.panel.title` 规范不一致**。
> **建议**：**保持现状**（不重命名已有 437 个 key，避免破坏），**新增文件**统一加 `pkrc` 前缀。
> 即在 `theme-config.json` 的 `i18n.namespacePrefix = "pkrc"` 只约束**新建**文件。

### 3.2 建议的 6 个新文件骨架

```json
// locales/zh-CN/pkrc-mingzuo.json   (命之座)
{ "ui": { "title": "命之座" }, "node": { "state": { "locked": "未解锁" } } }

// locales/zh-CN/pkrc-jieming.json   (解明)
{ "ui": { "title": "解明" }, "shield": { "broken": "护盾破碎" }, "seaGuard": { "name": "海之守护" } }

// locales/zh-CN/pkrc-eryou.json     (二游养成)
{ "ui": { "title": "养成 · 预选队伍" }, "action": { "exit": "退出" } }

// locales/zh-CN/pkrc-soudache.json  (搜打撤/PT)
{ "ui": { "title": "PT商店" }, "save": { "confirm": "是否保存当前队伍…" } }

// locales/zh-CN/pkrc-common.json    (共用)
{ "common": { "return": "返回", "close": "关闭", "cancel": "取消" } }
```

> ⚠️ **JSON 必须是合法 JSON（无注释）** —— v1 计划书里的 `jsonc` 注释是示意，实际产物 `JSON.parse` 会炸。

## 四、分批计划（S7-4 执行顺序）

> **原则**（v1 假设 4）：**先通用后系统**；每批独立验证；**不要一次抽完**。

| 批次 | 内容 | 条数（估） | 为什么这个顺序 | 依赖 |
|---|---|---|---|---|
| **B0** | **通用提示**（`pkrc-common`）：返回/关闭/取消/确认等高频词 | ~55 | 复用率最高，先做**一改全受益** | 无 |
| **B1** | **天赋补齐**（在现有 `talent.json` 437 keys 基础上补 L367/L372 残留） | ~200 | **唯一有先例的系统**，风险最低，可验证全流程 | B0 |
| **B2** | **命之座**（新建 `pkrc-mingzuo`） | ~408 | 条数第二多，结构清晰（节点/状态/描述） | B1 |
| **B3** | **解明**（新建 `pkrc-jieming`） | ~254 | 与命座风格接近，可复用抽取脚本 | B2 |
| **B4** | **二游养成**（新建 `pkrc-eryou`） | ~104 | 条数少，集中 L285-296 | B3 |
| **B5** | **搜打撤/PT**（新建 `pkrc-soudache`） | ~51 | 条数最少，**含存档相关文案需格外小心** | B4 |
| **B6** | **P5X / 原版残留甄别** | ~197 | 甄别"命中已 i18n"的 197 条，能复用就复用 | B5 |

**总计**：约 **1269 条需新增/补齐**（不含可复用的 ~197 条 + 已 i18n 的 437 条）

> **注**：约 **1011 条是"20 字以上长文案"**，其中大量是天赋/命座的**完整描述**（如 `fullDescription`）—— 这类**机械抽取最容易**（一一对应、无歧义），可脚本化。
> **真正需要人工判断的是 260 条短词**（1-4 字），它们可能是**原版 key 的残留**或**改版裸写**。

grep -o -E 'M\.t\("[^"]+"\)' game/server/dist/assets/loading-scene-By2k7Qfx.js \
  | sed 's/M\.t("\([^:]*\):.*/\1/' | sort | uniq -c | sort -rn

for k in 天赋 命之座 命座 解明 二游 搜打撤 养成; do

ls game/server/dist/locales/zh-CN/ | grep -E 'talent|mingzuo|jieming|eryou|soudache'

ls game/server/dist/locales/ | wc -l
