## 4. 关键决策

### 4.1 分层落位（遵守「数据层 ≠ UI Handler」约定）
- 逻辑/规则类 → 追加到既有**数据层**文件（`constellation-framework.ts`）或新建数据层文件（`eryou-abyss.ts`）。
- UI 界面类 → 新建 `constellation-ui.ts` / `p5x-turn-order.ts`，与既有 `eryou-ui.ts` 同一模式。

### 4.2 `PtConstellationUiHandler`（21 KB 单行类）→ **脚本机械转写，不手工排版**
- 该类含 40 个方法 / 41 个实例字段，手工转写必然出错 ⇒ 用 `f11-gen-constellation-ui.mjs`：
  1. 花括号配平提取 `const hO=class hO extends Yi{…}` 字节级原文；
  2. `hO` → `PtConstellationUiHandler`、`extends Yi` → `extends UiHandler`（`Yi`=`UiHandler`，产物 `l(ex,"UiHandler");let Yi=ex`）；
  3. `hO.MODE_OPTIONS` → 外置常量 `PT_CONSTELLATION_MODE_OPTIONS`（避免未声明静态属性）；
  4. 深度感知扫描类体，注入 41 条 `declare <field>: any;`（`declare` 不产出运行时代码，构造函数赋值照常）；
  5. 自动生成 62 条 `declare let`（外部 UI 依赖）；
  6. 5 条**类型补丁**（A3 minified 直译通病：`const A=[]`→`never[]`、`let d=null`→`null`、少参调用）。
- ⇒ 该类**逐字保留产物实现**，同时 `tsc` 0 错误。
