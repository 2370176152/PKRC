## 三、根因判断（两条，都需下一轮验证）

### 3.1 鼠标点击可能驱动不了 Phaser input

`Input.dispatchMouseEvent` 打到了 canvas，但 Phaser 的 input 系统通常需要**指针移动/悬停状态机预热**
才会把点击派发给游戏对象。**这能解释一个反差**：键盘（`dispatchKeyEvent`）能开主菜单、能推进 Phase，
但鼠标点击完全没反应。

> ⚠️ **必须先验证这一条**，否则继续校准坐标是白费。
> 验证方法：在主菜单点一个**已知位置的按钮**（如 Settings），看 `ui.getMode()` 变不变。
> - 变了 ⇒ 点击可用，只是 starter 卡片坐标不对，继续校准
> - 没变 ⇒ 是 Phaser input 问题，需在 `session.mjs` 的 `click` 里补 `mouseMoved` 预热

### 3.2 存档注入缺配套键

游戏读的 localStorage 键（`game-data.ts` 实测）：

| 类型 | 键名 |
|---|---|
| SYSTEM | `data_${username}` |
| SESSION | `sessionData` 或 `sessionData${slotId}` |
| SETTINGS | `settings` |
| MAPPING | `mappingConfigs` |

我只注入了 `sessionData4`，**没有 `data_Guest`**（SYSTEM 存档）⇒ `loadSession` 前置不满足
⇒ `sessionSlotId = -1`，游戏完全不认为有存档。
