### 4.3 `.orig` 签名来源（100% 物理可证）

`.orig` 文件头：

```js
const __vite__mapDeps=(i,m=__vite__mapDeps,d=(m.f||(m.f=["./jieming-anims-D_uicwAh.js","./index-D3KKGO7Y.js","./index-57B56a0n.css","./legendary-popup-helper-oMGPOaoa.js"])))=>i.map(i=>d[i]);
var kOe=Object.defineProperty;var l=(n,s)=>kOe(n,"name",{value:s,configurable:!0});
```

| 签名 | 来源 | 为何官方树复现不出 |
|---|---|---|
| `__vite__mapDeps` | Vite 对**动态 `import()`** 的依赖映射 | 数组 = **`jieming-anims`（自研解明系统 chunk）** 等；官方树无这些 import() |
| `var l=(n,s)=>kOe(n,"name",…)` | rollup 模式 name 注入器 | vite7+esbuild / vite8+rolldown 输出形态均不同 |
| `l(Class,"Name")` | 上述注入器调用点 | 依赖注入器存在 |
