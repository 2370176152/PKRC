## 3. 7 处错误的根因（**均为环境问题，非代码缺陷**）

### 3.2 `vite.config.ts` ×3

```

TS2353: 'tsconfigPaths' 不存在于 AllResolveOptions
```

**根因**：锚点树 `vite.config.ts` 面向 **vite 8 / rolldown**（`rolldownOptions` /
`minify:"oxc"` / `resolve.tsconfigPaths`），但 `package.json` 声明 **`vite: ^7.3.1`**、
`node_modules` 实装 **vite 7.3.1**、`pnpm-lock.yaml` **无 rolldown-vite**。

> → **锚点树自身存在依赖/配置不一致**（tarball 快照即如此），**非本迁移引入**。
> 旁证：`vite.config.ts.v8bak` 与 `vite.config.ts` **逐字节相同**（diff = 0），说明团队此前已在换配置。

## 4. 构建（PE-3）

### 4.1 降级方案

锚点树原配置在 vite 7 下无法构建（`#*` 别名不解析）。新增 **`vite.config.a313.ts`**，
**不改动** `vite.config.ts`，做四处等价降级：

| # | 原（vite 8） | 降级（vite 7） |
|---|---|---|
| 1 | `resolve.tsconfigPaths: true` | `vite-tsconfig-paths` + **显式别名兜底** |
| 2 | `build.minify: "oxc"` | `minify: false`（保留 keepNames 命名助手） |
| 3 | `build.rolldownOptions` | `build.rollupOptions` |
| 4 | 多目录别名（`#data/*` 等） | 自定义 `resolveId` 插件（模拟路径 fallback） |

> 补充：`vite-tsconfig-paths` 只为 tsconfig `include`（`*.ts`/`src`/`test`/`scripts-boilerplate`）
> 内的文件解析别名，而报错文件在 `plugins/` → 故对全部 `#*` 前缀加了显式别名。
