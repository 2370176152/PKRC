## 3. 符号还原规则

### 3.1 函数 / 类名反查（核心）

魔改者用 esbuild `keepNames` 保留了名字，产物形态：

```js
function 短名(...){...} l(短名,"原函数名");
class 短名 extends 基类{...} l(短名,"原名"); let X=短名;
```

**还原步骤**：
1. 用 `.build-tools/extract-symbol.py <原名>` 定位（支持 function/class/assign 三形态）。
2. 提取完整函数体（花括号配平，见 `.build-tools/nianli-full.py` 的 `get_fn`）。
3. TS 中**用原名**命名导出函数，并在注释标注产物短名：
   ```ts
   /** 产物 `RPe` — 群体招式每回合限一次的获得层数 */
   export function tryGainFromSpreadMove(pokemon: any): void { ... }
   ```

### 3.2 「产物符号 → 原名」对照表模板

每个文件头必须有对照表。标准模板（可直接复制填写）：

| 产物短名 | 还原原名 | 作用 | 类型 |
|---|---|---|---|
| `hI` | `registerConstellation` | 注册系统命座 | function |
| `REe` | `CONSTELLATION_CODEX_REGISTRY` | codex 注册表 | const |
| `p` | `Stat` | 能力枚举 | import |

### 3.3 常量还原

产物常量可能是 `const A=1,B=2`（逗号链）或 `A=1`（裸全局赋值）。定位用：
```
python .build-tools/node-vals.py <符号列表>
```
**每个 TS 常量注释里必须写清数值 + 产物符号**：
```ts
export const NIANLI_MAX_DEFAULT = 2; // 产物 `kfe`
```

### 3.4 中文串（行为契约）—— 逐字保留

**中文串是最高优先级的行为契约**：魔改者用中文写日志/文案，压缩后原样保留。
- 一律**逐字复制**，不翻译、不改写、不补全标点。
- 内嵌系统规格（`[{name:"系统名",description:...}]`）**必须整段保留**为 `*_CODEX` 常量。
- 每个中文串都是 A4 验收锚点。

## 4. 依赖处理规则

产物中引用的上游 API（类、枚举、场景对象）一律用**占位声明**，不臆造签名：

```ts
// ── 依赖（上游 API，待接入锚点源码时改为真实 import）──
declare const globalScene: any; // 产物 `E`
declare const Stat: any;        // 产物 `p`（Stat enum）
declare function addBattlerTag(pokemon: any, tag: string, opts?: any): void; // `kn`
```

**规则**：
- 占位名 = 语义名（不是产物短名），注释标产物短名。
- 参数类型优先 `any`（接入时再收窄），**不得编造**不存在的参数。
- 文件末尾**必须**有 `TODO(接入锚点 90df65097b6d)` 区块，列出所有待替换的 import。

## 7. 自检清单（文件级 DoD）

迁移一个系统文件，逐条勾选：

- [ ] 文件头含 5 要素：系统名 / 来源 chunk / 逆向方式 / 锚点树 / 定位
- [ ] 文件头含「产物符号 → 原名」对照表
- [ ] 所有导出函数名 = 产物原名（`l()` 反查），注释标产物短名
- [ ] 所有常量注释含 数值 + 产物符号
- [ ] 中文串逐字保留；系统内嵌规格整段保留为 `*_CODEX`
- [ ] 依赖用 `declare` 占位，文件末尾有 `TODO(接入锚点 90df65097b6d)` 区块
- [ ] TODO 标记全部符合 §5 分类
- [ ] §6.1 语法验证 `EXIT=0`
- [ ] §6.2 中文串守恒无 orphan
- [ ] 若系统接入命座框架 → 已调 `registerConstellation`，且 `exclusiveNodes` 与产物一致
