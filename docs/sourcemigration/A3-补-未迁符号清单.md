|---|---|---|---|---|
| **A. 上游 API** | 产物短名在锚点树有同名真实符号 | `E`/`V`/`Yi`/`F`/`re`/`dt`/`w`/`M`/`Qs` | 换成真实 `import`，`as` 回产物短名 | `E`→`globalScene as E` · `re`→`addTextObject as re` |

> `declare let X: any`（实测 `eryou-ui.ts:158 declare let add: any;` 即 `EryouList.add` 的方法名）。
> 若照 A/B/C 三类处理，会把方法名错改成 import ⇒ 引入**假 import + 编译错**。
> **判别法**：在类体（`class ... extends Yi{` 到配平花括号尾）之外若该标识符无任何独立引用 ⇒ 是方法名，直接删 declare。

### 49.4 🔴 提取器的 3 次修正（**括号配平必须处理形参默认值**）

`formChangeTargetsFor(n,s,i={})` 的形参默认值里就有花括号 ⇒ 朴素的 `indexOf("{", at)` 会截断。

| 版本 | 做法 | 结果 |
|---|---|---|
| v1 | `S.indexOf("{", at)` | 66/66，但**含默认值那个被截断** |
| v2 | 从 `at` 起配平 + 跳过到 `{` | **4/66**（把普通函数也拒了） |
| v3 | 只判 `d===0` 时撞 `{` | **5/66** |
| ✅ **v4** | `(` 增 / `)` 减；`d<=0` 时遇 `{` 或 `;` 即停 | **66/66** |

🔴 **判据**：压缩产物的函数定义有三种形态 ——
`function f(形参){body}`（re 停在 `(`）/ `f=(形参)=>body` / `f=function(){body}` / `f={...}`，
**必须统一用「括号配平 + 顶层 `{`/`;` 双判定」**，不能靠 `indexOf` 猜。
