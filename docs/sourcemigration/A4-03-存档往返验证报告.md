## 6. 🔴 附带发现并修复：**A5-01 切换导致签名基准失效**

| 项 | 说明 |
|---|---|
| **现象** | A5-01 把 `game/server/dist/assets` 换成了**自构建产物** ⇒ `verify-signature.cjs` 的默认基准路径指向了**候选自身** |
| **后果** | 若不修，签名比对变成「自构建 vs 自构建」⇒ **覆盖率虚高至接近 100%**，M3 判定门会**误判通过** |
| **修复** | `tools/verify-signature.cjs` 增加 `detectBaseline()`：**自动探测 `game/server/dist.modder-backup-*/assets`**（取最新），CLI `--baseline` 仍可覆盖 |
| **回归验证** | 修复后复跑：基准 = `dist.modder-backup-20261016/assets`（3125 符号）⇒ 覆盖率 **67.78%**（与切换前一致）✅ |

> **⇒ 这条修复避免了 M3 判定门（A4-00b-4）的一次系统性误判。**
