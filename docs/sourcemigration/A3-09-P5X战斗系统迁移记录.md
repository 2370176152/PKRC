## 3. 核心机制要点

### 3.1 通用回合效果框架

```ts
pokemon.p5xEffects = {
  [key]: { rounds?: number, turns?: number, ... }   // rounds=轮, turns=回合
}
```

- **`applyP5XEffect`（`kn`）**：已存在则 `rounds`/`turns` **取较大值刷新**（不是覆盖）；可顺带注册过期回调；发 `p5xEffectApplied` 事件。
- **`tickEffects`（`Cae`）**：仅递减**存在**的字段；`rounds` 与 `turns` **同时为 0** 才过期（任一 > 0 则保留）。
- **`expireP5XEffect`**：删除 + 触发注册表回调；**`clearP5XEffect`（`uw`）不触发回调**（区别关键）。
- **`settleP5XRoundEffects`（`cw`）**：以 `battle` 引用 + `turn` 作**幂等游标**，同一回合只结算一次。

### 3.2 承伤倍率（`vuln:` / `resist:`）

效果 **key 本身编码数值**：`vuln:0.3` / `resist:0.15`。
`getIncomingDamageMultiplier` 遍历所有 key，按前缀累乘 `(1+n)` / `(1−n)`；解析失败按 0。

### 3.3 状态图标注册表（`$te`）

18 条图标定义（中文逐字保留），跨系统复用：
`shock:*`（蓄雷）/ `nian-li:overflow`（念力）/ `chiXin:window`（潜心）/ `meloetta:*`（旋律）/ `mew:*`（属性编织）/ `healer:*`（余响）/ `eryou-abyss:*`（深渊）。
`findP5XStatusIcon` 支持 `xxx:` **前缀族兜底**（`eryou-abyss:attack:0` 命中 `eryou-abyss:attack:`）。

### 3.4 P5X 规则

- **`isP5XFieldable`（`GB`）**：`isP5X ? (!hasJiemingConstellation(p) && !isP5XRestrictedTierSpecies(p.species)) : true`
  → **依赖解明**（解明角色不上场，验证了 A3-07 收敛的正确性）。
- **`isP5XRestrictedTierSpecies`（`nN`）**：`legendary || subLegendary || mythical || species==="Paradox Pokémon"`。
- **道具**：P5X 下每波每种消耗品限一次（`p5xUsedConsumableIds`）；持有物限 1 个。
- **`applyP5XIvs`（`aae`）**：P5X 强制个体值全 15（`uHe`）。
