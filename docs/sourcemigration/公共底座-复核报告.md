## 3. 勘误 E4 明细：遗漏常量 `DT`

**产物常量链**（@1871537）：
```js
qA=6, lU=[2,3,4,6,8,10], DT=1e4, nSe={1:15,2:20,5:25}, ASe=1.2, aSe=1.15, ESe=[1,2,3,4,5], ...
```

**`DT` 语义**（用法证据）：
```js
// 命座重置
if (L < DT) throw new Error(`PT不足，需要 ${DT} PT。`);
E.gameData.addPt(-DT);
// UI 文案
`重置全部命座？返还 ${IEe(i)} 颗觉醒石，消耗 ${DT} PT。再点一次「重置命座」确认。`
`重置命座 (${DT} PT)`
this.resetText.setColor(s.pt() >= DT ? Dne : fne)
```

**结论**：`DT` = **重置全部命座的 PT 消耗 = 10000**。
**A3-01 遗漏** → 迁移版命座重置功能会缺此常量（若按 A3-01 实现会 undefined）。
**已补**：`CONSTELLATION_RESET_PT_COST = 10000`，并登记勘误 E4。
