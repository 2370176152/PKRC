## 六、🔴 本次迁移最重要的方法论（**留给后续接手者**）

### 6.1 `A3-补` 必须「先接入口，再补叶子」

| 做法 | 工作量 | 命中 Δ |
|---|---|---:|
| 先补叶子（25 个函数） | 大 | **+0** |
| **接上链入口（5 行调用）** | **小** | **+29** |

**根因**：rolldown 从**入口**做可达性分析 —— 入口不可达，整条链（含叶子）全部被摇掉。
**⇒ 补任何符号前先问：「这条链的入口被谁调用？」**

### 6.2 其他固化经验

| 主题 | 要点 |
|---|---|
| **短名映射** | **一律用 `l(短名,"原名")` keepNames 反查，禁止猜**（勘误 E10 教训：我猜 `aNe` 导致映射全错） |
| **`stub/stub.ts`** | 里面的自造枚举会**掩盖真实归属**（E11：`#enums/damage-result` 实为上游 `HitResult`） |
| **`declare ... any`** | 掩盖真实类型不匹配 ⇒「文件已落位」**≠**「类型正确」；`(d1)「归零」= 落位且类型修净` |
| **变参签名** | `setOverlayMode(mode, ...args)` 会**吞掉多余实参、`tsc` 不报错**（E13）⇒ 转录须逐字比对 |
| **同名跨枚举** | 必须核 **ctor 形参声明的枚举类型**（E12：`Ut` 是 `Challenges` 非 `ChallengeType`） |
| **`Symbol` 占位** | A3 曾把 UI 函数写成 `Symbol.for(...)`（E14）⇒ 调用即失效 |
| **签名数字会误导** | A3-补 单独做会让 tree-shake **上升**（新导出无调用点）；必须与 patch **成对做** |
