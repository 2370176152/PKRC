📖 使用说明

1. 修改存档

  1. 点击「加载存档文件」，选择 Save 文件夹中的 .prsv 文件
  2. 在「批量修改」「宝可梦编辑」或「精细编辑」中修改数据
  3. 点击「保存修改」，下载修改后的 .prsv 文件

2. 将修改后的存档导入游戏

⚠ 推荐方式：游戏内导入

  1. 启动游戏，进入标题画面
  2. 点击底部的「设置」图标 → 选择对应存档类型的「导入」
  3. 选择修改后的 .prsv 文件
  4. 确认导入后游戏会自动刷新

⚠ 备选方式：覆盖 Save 文件夹

  1. 关闭游戏
  2. 将修改后的文件重命名为原文件名（如 sessionData_Guest.prsv）
  3. 覆盖 Save 文件夹中的对应文件
  4. 删除游戏浏览器数据（或按 F12 清除 localStorage）
  5. 重新启动游戏

3. 存档文件说明

  • data_Guest.prsv - 系统存档（图鉴、统计、奖券等）
  • sessionData_Guest.prsv - 会话存档（当前游戏进度，槽位0）
  • sessionData1_Guest.prsv - 会话存档槽位1
  • runHistoryData_Guest.prsv - 通关历史记录

4. 注意事项

  • 修改前请备份原始存档文件
  • 精细编辑模式下请谨慎修改，避免破坏数据结构
  • 物种ID必须是有效的宝可梦编号
  • 性格值范围为 0-24
  • 等级需为正整数；无尽模式等级可超过 100
  • 「图鉴编辑」仅修改 data 系统存档；可编辑捕获解锁、形态、闪光、蛋招式、特性和图鉴 IV
  • 图鉴面板提供「一键解锁当前宝可梦」和「一键全解锁图鉴」；全解锁会覆盖图鉴 IV，并弹窗确认
  • 「宝可梦编辑」中的本体形态与融合形态分别作用于 session 对局宝可梦
  • 融合宝可梦可按名称选择；融合形态、特性和闪光等级会按对应宝可梦更新
  • 融合自定义数据选择“使用默认”时会保留 -1 或 null，表示继承物种设置
